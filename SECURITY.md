# Security policy

## Supported versions

Security fixes are considered for:

- The **latest tagged release** on [Releases](https://github.com/lampac-nextgen/lampac/releases)
- The **`main`** branch

Older tags are generally not patched separately; upgrade to the latest release when possible.

## Reporting a vulnerability

Please report security issues **privately** via GitHub’s private vulnerability reporting:

**[Report a vulnerability](https://github.com/lampac-nextgen/lampac/security/advisories/new)**

Do **not** open a public issue, discussion, or PR with exploit details.

Include as much as you can: affected version or commit, deploy type (Docker / native / Windows), impact, and steps to reproduce. We will acknowledge reports when possible and coordinate a fix before any public disclosure.

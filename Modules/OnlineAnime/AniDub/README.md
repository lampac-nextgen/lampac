# AniDub

Онлайн-источник **AniDub** (`OnlinesSettings`): базовый URL — **`https://online.anidub.com`**, **`streamproxy = false`**. Аниме: и сериалы, и полнометражки.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Поведение

- **`Invoke`** возвращает **`new(conf)`** и для сериалов, и для фильмов.
- Каталог только поисковый: своей страницы со списком у площадки нет, карточки берутся из выдачи DLE. Запросу нужны **`full_search=0&result_from=1&search_start=0`** — без них сайт отдаёт пустую форму поиска вместо выдачи.
- На AniDub каждый сезон — отдельная страница, поэтому список сезонов собирается из нескольких результатов поиска: кандидаты разворачиваются параллельно, до **`SeasonWorkers`** воркеров. Номер сезона читается из названия тайтла (**«ТВ-2»**, **«2 сезон»**), потому что на самих страницах почти везде стоит **«Сезон 1»** — студия нумерует серии внутри своего релиза, а не внутри сериала.
- Тайтлы на мёртвых плеерах пропускаются.

## Два источника потока

- **Общий плеер** (**`player*.ladonyvesna2005.info`**, до **1080p**): список серий берётся из плейлиста плеера, качество — из **`event-filename`**. Поле **`RESOLUTION`** в манифесте врёт.
- **Sibnet** (до **720p**): у большей части каталога общего плеера нет вовсе — серии разложены вставками **`video.sibnet.ru/shell.php?videoid=…`** прямо на странице тайтла. Путь к файлу добывается из **`shell.php`**, разрешение — из **`og:title`** вставки.

## Глобальный поиск

**`with_search.Add("anidub")`**.

## Подпись качества

**`OnlineApiQuality`**: при **`e.balanser == "anidub"`** → **` ~ 1080p`**.

## Конфигурация

Секция в `init.conf`: **`AniDub`** (`OnlinesSettings`). **`httptimeout = 6`**: часть узлов отвечает не сразу, а плеер запрашивается повторно.

## HTTP

| Маршрут | Назначение |
|---------|------------|
| **`lite/anidub`** | Фильм или список сезонов. |
| **`lite/anidub`** c **`s`** | Серии сезона. |
| **`lite/anidub/play`**, **`lite/anidub/play.m3u8`** | Поток. |

## Особенности потока

- У общего плеера ссылка на master-плейлист подписана **User-Agent** клиента и узлом CDN. Поэтому master запрашивается UA клиента, он же уходит клиенту в заголовках, а **`streamproxy`** выключен — через сервер запрос ушёл бы с чужим UA и подпись не сошлась бы. Узлы **`cdnN.anivids.link`** ротируются случайно на каждый запрос, и часть из них нерабочая: негодный узел клиенту не отдаётся, модуль переспрашивает master, пока не выпадет живой.
- У sibnet ссылку на **`video.sibnet.ru`** пускают только с **`Referer`** своего же хоста — без него **403**, а плеер этого заголовка не шлёт. Поэтому оба редиректа до CDN модуль разрешает на сервере и отдаёт клиенту уже готовый адрес: он живёт около восьми часов и заголовков не требует вовсе.

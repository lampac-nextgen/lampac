# KubikVKube — источник «Кубик в Кубе» для LampacNG

Онлайн-источник для [LampacNG](https://github.com/lampac-nextgen/lampac) (проверен на **1.60.0**),
который берёт релизы с сайта студии **kubikvkube.com** и отдаёт **все озвучки** всех плееров сайта.
Озвучка Кубика (та, что сайт ставит приоритетной, обычно 18+) — первой, затем остальные озвучки Кубика,
затем прочие студии.

> **О прокси.** Основные плееры (VideoHub и VK Видео) российский прокси не требуют.
> Запасной плеер `/lat/` отдаёт данные только российским IP: с зарубежного сервера без прокси он отвечает
> `lat:…:геоблок`, и работают только релизы, у которых есть VideoHub или VK.
> Чтобы запасной плеер заработал, добавьте российский прокси (`useproxy` + `proxy.list`, см. ниже).

## Установка

Установщика нет: модуль ставится копированием папки. Перед правкой `init.conf` сделайте его копию.

**1. Скопируйте папку модуля** в каталог `mods` вашего LampacNG:

```bash
cp -r KubikVKube /opt/lampac/mods/
```

(каталог установки может отличаться; `mods` — папка для собственных модулей рядом с `module`).

**2. Секция в `init.conf` необязательна**: модуль работает с умолчаниями. Чтобы что-то изменить, добавьте
секцию `KubikVKube` на верхний уровень файла (объедините с существующим содержимым, а не заменяйте файл).
Пример — в `init.merge.example.json`.

**3. Перезапустите LampacNG.** Модули из `mods` компилируются при старте:

```bash
systemctl restart lampac        # имя сервиса может отличаться
journalctl -u lampac -b --no-pager | grep -E "CS[0-9]{4}|compilation error|KubikVKube"
```

В журнале должна появиться строка `[KubikVKube] loaded`. **Ошибка компиляции в любом модуле из `mods`
останавливает запуск всего LampacNG.** Откат: вынуть папку модуля из `mods` и перезапустить сервис.

**4. Проверьте:**

```bash
curl -sG "http://127.0.0.1:9118/lite/kubikvkube" \
  --data-urlencode "rjson=true" --data-urlencode "title=Гангстерленд" \
  --data-urlencode "original_title=MobLand" --data-urlencode "year=2025" \
  --data-urlencode "kinopoisk_id=5512084" --data-urlencode "serial=1" \
  --data-urlencode "uid=ВАШ_UID"
```

`uid` нужен, если на сервере включён `accsdb`.

## Как работает

```
Lampa → /lite/kubikvkube
          │
          ├─ 1. поиск на kubikvkube.com (DLE-поиск по названию / оригинальному названию)
          │     проверка страницы: id Кинопоиска со страницы == kinopoisk_id карточки,
          │     иначе — оригинальное название + год
          │
          ├─ 2. со страницы релиза берутся ВСЕ плееры сайта:
          │     • «Смотреть онлайн» = VideoHub  <video-player data-title-id=KP data-publisher-id=…>
          │     • заливки студии в VK  <iframe src="https://vkvideo.ru/video_ext.php?oid=…&id=…&hash=…">
          │     • «Запасной плеер»  = движок /lat/  <iframe src="//…/lat/ID?voice=10">
          │
          ├─ 3. всё сводится в один список: сезоны → озвучки → серии;
          │     одна и та же студия из разных плееров — одна строка
          │
          └─ /lite/kubikvkube/video?…&p=vh,vk,lat  (по нажатию на серию)
                • VideoHub и VK: HLS + прямые mp4 по качествам (2160p…360p)
                • если первый плеер не отдал поток — та же серия из следующего,
                  без участия пользователя
```

Отличия от штатных модулей:

* **CDNvideohub** (штатный) берёт только HLS и показывает все студии; здесь — прямые mp4 по качествам,
  Кубик первым и резерв из других плееров.
* **Gencit** (штатный, тот же движок `/lat/`) работает только по id Кинопоиска/IMDb и только для сериалов;
  здесь — поиск по каталогу сайта, фильмы и мультфильмы, и VideoHub как основной плеер.

Студия переводит зарубежное, поэтому для релизов с `original_language = ru` источник не показывается.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `lite/kubikvkube` | поиск, сезоны, озвучки, серии (`similar=true` — список «Уточнить») |
| `lite/kubikvkube/video` | поток серии/фильма с автопереключением плееров |

## Параметры `init.conf` (секция `KubikVKube`) — все необязательные

```json
"KubikVKube": {
  "enable": true,
  "displayindex": 520,
  "onlykubik": false,
  "mp4": true,
  "usevh": true,
  "usevk": true,
  "uselat": true,
  "lathosts": ["https://tomion.org", "https://ylitron.pro"],
  "streamproxy": true
}
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `onlykubik` | `false` | `true` — оставить только озвучки «Кубик в Кубе» |
| `mp4` | `true` | прямые mp4 (VideoHub, VK) в меню качества плеера |
| `usevh` / `usevk` / `uselat` | `true` | включить или выключить плеер |
| `lathosts` | `tomion.org`, `ylitron.pro` | зеркала запасного плеера (домен со страницы пробуется первым) |
| `streamproxy` | `true` | ссылки VK/OK привязаны к IP сервера — без прокси потока часть клиентов получит 403 |
| `useproxy` + `proxy.list` | — | SOCKS/HTTP-прокси для запросов модуля; нужен, чтобы заработал запасной плеер `/lat/` с зарубежного сервера |
| `httptimeout` | `8` | секунд на запрос |
| `displayindex` | `520` | позиция источника в списке |

Секция подхватывается на лету (hot-reload), перезапуск после правки `init.conf` не нужен.

Пример с российским прокси для запасного плеера:

```json
"KubikVKube": {
  "enable": true,
  "useproxy": true,
  "proxy": { "list": [ "socks5://USER:PASSWORD@PROXY_HOST:PORT" ] }
}
```

## Ограничения

* Запасной плеер (`/lat/`) отдаёт данные только на российские IP. С зарубежного IP в сообщении об ошибке
  будет `lat:…:геоблок` — тогда работают только релизы с VideoHub или VK. Лечится `useproxy` с российским прокси.
* У части старых релизов VideoHub не подписывает студию — такие озвучки показываются с пометкой «· без подписи».
* Сайт без id Кинопоиска на странице (только запасной плеер) сверяется по оригинальному названию и году.
* VK Видео: модуль получает **анонимный** токен публичного веб-клиента VK (без аккаунта и без логина).
  Если VK изменит этот механизм, VK-плеер перестанет отдавать потоки; остальные плееры продолжат работать.
* Если сайт или плееры сменят вёрстку или адреса, модуль придётся править.

## Диагностика

```bash
journalctl -u lampac -b --no-pager | grep -E "KubikVKube|error CS"
```

Типичное сообщение: `Нет доступных озвучек (vh:нет на странице; lat:tomion.org:геоблок,…)` — релиз найден,
но ни один плеер не отдал данные. Расшифровка: `vh:` — VideoHub, `vk:` — VK Видео, `lat:` — запасной плеер.

## Состав

| Файл | Назначение |
|---|---|
| `ModInit.cs` | регистрация источника «Кубик в Кубе», загрузка конфига, горячая перезагрузка `init.conf` |
| `ModuleConf.cs` | настройки модуля |
| `Controller.cs` | маршруты `lite/kubikvkube` и `lite/kubikvkube/video` |
| `KubikService.cs` | сеть и разбор: сайт, VideoHub, VK, запасной плеер `/lat/` |
| `Models.cs` | модели данных |
| `manifest.json` | описание модуля для динамической компиляции (Roslyn) |
| `KubikVKube.csproj` | проект для сборки вместе с исходниками LampacNG (на сервере не нужен) |
| `init.merge.example.json` | пример секции для `init.conf` |

## Замечание

Модуль только читает публичные страницы сторонних сайтов и ничего не хранит и не раздаёт.
Пользуйтесь им в личных целях и в соответствии с законодательством вашей страны.

# Redheadsound — источник «RHS» (RedHeadSound) для LampacNG

> ## ⚠️ Нужен российский прокси
>
> Сайт RedHeadSound и его плеер **ladoni.pro** (страница плеера, мастер-плейлист m3u8 и сегменты видео)
> отдают данные **только российским IP**. С любого другого адреса сайт закрыт, а плеер возвращает
> заглушку на 545 байт с кодом `200` — модуль в этом случае ничего не найдёт и не воспроизведёт.
>
> Если ваш сервер LampacNG стоит **за пределами РФ**, в секции `Redheadsound` файла `init.conf`
> обязательно нужны **все три** параметра: `useproxy`, `useproxystream` и `proxy.list`
> с российским SOCKS5/HTTP-прокси (см. [Установка](#установка)).
> Глобальный прокси с `pattern` на домен сайта **не подходит**: он не покрывает `ladoni.pro`.
>
> Если сервер сам имеет российский IP, прокси не нужен. У автора сервер за границей,
> этот вариант отдельно не проверялся.

Онлайн-источник для [LampacNG](https://github.com/lampac-nextgen/lampac): берёт релизы с сайта
**RedHeadSound** и воспроизводит их через собственный плеер сайта (ladoni) — **без браузера**.
В списке источников Lampa называется «RHS». Проверен на LampacNG **1.60.0**.

## Что делает

* Ищет фильм или сериал на сайте RHS (DLE-поиск по названию и оригинальному названию).
* Из плеера сайта берёт сезоны, серии и **все озвучки ladoni** (RHS первой, затем остальные студии).
* Отдаёт потоки 1080p / 720p / 480p / 360p; видео идёт через stream-proxy LampacNG и российский прокси.
* Сайт часто меняет адрес — модуль перебирает зеркала (`mirrors`) и запоминает рабочее на 30 минут.

## Как это работает

```
Lampa → /lite/redheadsound?title=…                 поиск на сайте RHS (через прокси)
      → карточка сайта → iframe ladoni.pro/lat/{ID}
      → GET ladoni.pro/lat/{ID}  (через прокси)     → window.playerData: сезоны, серии, озвучки
Lampa → /lite/redheadsound/ladoni?lat=ID&s=S&e=E&v=VOICE
      → playerData.config.video = master m3u8 (подписан, живёт около 3 часов)
      → stream-proxy LampacNG (useproxystream) → Lampa
```

Страница плеера содержит всё нужное прямо в HTML (`window.playerData`), поэтому Chromium/Playwright
не требуется. Старый режим через браузер оставлен в коде как запасной (`"ladonimode": "card"`), по умолчанию
выключен и в обычной работе не нужен.

## Установка

Установщика нет: модуль ставится копированием папки. Перед правкой `init.conf` сделайте его копию.

**1. Скопируйте папку модуля** в каталог `mods` вашего LampacNG:

```bash
cp -r Redheadsound /opt/lampac/mods/
```

(каталог установки у вас может отличаться; `mods` — папка для собственных модулей рядом с `module`).

**2. Добавьте секцию в `init.conf`** (на верхний уровень, рядом с другими секциями; не заменяйте весь файл —
объедините). Пример — в файле `init.merge.example.json`:

```json
"Redheadsound": {
  "enable": true,
  "useproxy": true,
  "useproxystream": true,
  "proxy": {
    "list": [ "socks5://USER:PASSWORD@PROXY_HOST:PORT" ]
  }
}
```

* `useproxy` — запросы к сайту и странице плеера идут через прокси;
* `useproxystream` — m3u8 и сегменты видео тоже идут через прокси;
* `proxy.list` — ваш российский прокси. Формат `socks5://логин:пароль@хост:порт` или `http://…`.

> `init.conf` — JSON в UTF-8 (в LampacNG он может быть с BOM). Редактируйте так, чтобы не потерять кодировку.
> Ошибка в JSON блокирует чтение всего файла.

**3. Перезапустите LampacNG.** Модули из `mods` компилируются при старте:

```bash
systemctl restart lampac        # имя сервиса может отличаться
journalctl -u lampac -b --no-pager | grep -E "CS[0-9]{4}|compilation error|Redheadsound"
```

Пусто в этом выводе — компиляция прошла. **Ошибка компиляции в любом модуле из `mods` останавливает запуск
всего LampacNG.** Откат: вынуть папку модуля из `mods` и перезапустить сервис.

**4. Проверьте:**

```bash
curl -sG "http://127.0.0.1:9118/lite/redheadsound" \
  --data-urlencode "rjson=true" --data-urlencode "title=Пацаны" \
  --data-urlencode "serial=1" --data-urlencode "uid=ВАШ_UID"
```

Должен вернуться JSON со списком сезонов. `uid` нужен, если на сервере включён `accsdb`
(без него запрос до модуля не доходит и ответ пустой или с ошибкой доступа).

Список озвучек и серий выбранного сезона:

```bash
curl -sG "http://127.0.0.1:9118/lite/redheadsound" \
  --data-urlencode "rjson=true" --data-urlencode "title=Пацаны" \
  --data-urlencode "serial=1" --data-urlencode "s=1" --data-urlencode "uid=ВАШ_UID"
```

## Параметры `init.conf` (секция `Redheadsound`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enable` | `true` | включить источник |
| `useproxy` | — | **обязательно вне РФ**: сайт и плеер ladoni пускают только российские IP |
| `useproxystream` | — | **обязательно вне РФ**: m3u8 и сегменты видео тоже только с российского IP |
| `proxy.list` | — | список российских прокси |
| `host` / `mirrors` | `redheadsound3.top` / `redheadsound3`, `1`, `2`, `.top` | сайт и его зеркала, перебираются по порядку |
| `ladoniallvoices` | `true` | показывать все озвучки ladoni; `false` — только RHS |
| `ladonicache` | `3` | минут кэша страницы плеера и ссылки (ссылка подписана временем) |
| `httptimeout` | `40` | секунд на запрос; через прокси сайт может отвечать 7–18 с |
| `m4s` | `true` | разрешать 1440p/2160p, если плеер их отдаёт |
| `debug` | `false` | печатать шаги модуля в журнал |
| `ladonimode` | `http` | `http` — без браузера. Режимы `card`/`fake` — старый путь через Chromium, **не включайте** |
| `ladonitimeout`, `ladoniclicks`, `ladoniabortads`, `ladoniqualities`, `ladonimindur` | | только для старого режима `card` |

Значения из `init.conf` **перекрывают** умолчания модуля. Если вы когда-то включали `"ladonimode": "card"`
и потом обновили модуль — удалите этот ключ из секции, иначе останется старый режим.
Админ-панели, сохраняющие секцию целиком, могут записать в неё все внутренние поля;
это не ломает работу, но «замораживает» старые значения.

## Озвучки

* «Red Head Sound» всегда первая (`t=1`). У сайта две дорожки RHS (дубляж и обычная); модуль объединяет
  их в одну строку и для каждой серии берёт ту, что есть.
* Остальные озвучки плеера — по числу серий, `t = 1000 + id озвучки`.
* `"ladoniallvoices": false` оставит только RHS.

## Диагностика

Включите `"debug": true` и смотрите журнал:

```bash
journalctl -u lampac -f -o cat | grep -E "Redheadsound"
```

| Признак | Причина |
|---|---|
| `lat https://ladoni.pro/lat/… -> s1e2 voice …` | всё хорошо |
| `нет данных плеера (545 байт, заглушка)` | ladoni видит **не российский IP**: нет `useproxy`/`proxy` в секции |
| `403` на `/proxy/….m3u8` в плеере | нет `useproxystream` |
| ответ `503`, тело `site` | на сайте нет карточек: сайт не ответил или такого тайтла нет |
| ответ `503`, тело `ladoni` | карточка есть, но плеер не ответил или в карточке нет iframe `/lat/` |
| ответ `chromium disabled` | в секции остался `ladonimode: card/fake` — удалите ключ |

Важно: HTTP `200` от ladoni **не означает успех**. Настоящую страницу плеера (около 43 КБ) отличает наличие
`window.playerData = {…}`; заглушка для чужого IP весит 545 байт.

## Ограничения

* Всё видео идёт через ваш прокси. Если 1080p подвисает — берите более быстрый прокси или выбирайте 720p.
* Источник показывает ровно то, что выложено у RHS. Если сайт или плеер сменят вёрстку или адреса —
  модуль придётся править.
* Сайт RHS периодически меняет домен; список `mirrors` можно дополнять в `init.conf`.
* Проверено на LampacNG 1.60.0.

## Состав

| Файл | Назначение |
|---|---|
| `ModInit.cs` | регистрация источника «RHS», загрузка конфига, горячая перезагрузка `init.conf` |
| `ModuleConf.cs` | настройки модуля |
| `Controller.cs` | маршрут `lite/redheadsound` (поиск, сезоны, озвучки, серии) |
| `Ladoni.cs` | поиск на сайте, зеркала, маршрут `lite/redheadsound/ladoni`, старый режим через Chromium |
| `Api.cs` | разбор `playerData`: сезоны, озвучки, серии, ссылка на поток |
| `Service.cs` | заголовки для stream-proxy |
| `StreamData.cs` | модели данных |
| `manifest.json` | описание модуля для динамической компиляции (Roslyn) |
| `Redheadsound.csproj` | проект для сборки вместе с исходниками LampacNG (на сервере не нужен) |
| `init.merge.example.json` | пример секции для `init.conf` |

## Замечание

Модуль только читает публичные страницы сторонних сайтов и ничего не хранит и не раздаёт.
Пользуйтесь им в личных целях и в соответствии с законодательством вашей страны.

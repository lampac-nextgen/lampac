# RuDub

Онлайн-источник **RuDub** (`OnlinesSettings`): базовый URL — **`https://play26.ru-dub.xyz`**, **`streamproxy = false`**. Только сериалы — фильмов на площадке нет.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Поведение

- **`Invoke`** возвращает **`new(conf)`** только при **`args.serial == 1`**.
- Сезоны резолвятся параллельно, до **`SeasonWorkers`** воркеров.
- Сезоны на мёртвых плеерах пропускаются: примерно половина каталога лежит на старых плеерах, которые не отвечают.
- Узлы CDN (`cdnN.anivids.link`) ротируются случайно на каждый запрос master-плейлиста, и часть из них нерабочая. Негодный узел клиенту не отдаётся: модуль переспрашивает master, пока не выпадет живой.

## Глобальный поиск

**`with_search.Add("rudub")`**.

## Подпись качества

**`OnlineApiQuality`**: при **`e.balanser == "rudub"`** → **` ~ 1080p`**.

## Конфигурация

Секция в `init.conf`: **`RuDub`** (`OnlinesSettings`). **`httptimeout = 6`**: часть узлов отвечает не сразу, а плеер запрашивается повторно.

## HTTP

| Маршрут | Назначение |
|---------|------------|
| **`lite/rudub`** | Сезоны. |
| **`lite/rudub`** c **`s`** | Серии сезона. |
| **`lite/rudub/play`**, **`lite/rudub/play.m3u8`** | Поток. |

## Особенности потока

Ссылка на поток подписана **User-Agent** клиента и узлом CDN: тот же адрес с чужим UA или на соседнем узле отдаёт **403**. Поэтому master-плейлист запрашивается UA клиента, он же уходит клиенту в заголовках, а **`streamproxy`** выключен — через сервер запрос ушёл бы с чужим UA и подпись не сошлась бы.

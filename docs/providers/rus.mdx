## FlixCDN

FlixCDN получает ссылки через официальный плеер в отдельном headed Chromium. Значение глобального параметра `chromium.Headless` не меняется. Браузер запускается только при отсутствии результата в кеше и закрывается после пяти минут простоя.

Включите Chromium и сам источник в `init.conf`:

```json
{
  "chromium": {
    "enable": true
  },
  "FlixCDN": {
    "enable": true
  }
}
```

<Info>
  Официальный Docker-образ содержит Chromium и Xvfb. При запуске Lampac без Docker установите Chromium и `/usr/bin/Xvfb` самостоятельно.
</Info>

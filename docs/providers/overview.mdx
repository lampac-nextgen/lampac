## Группы провайдеров

Провайдеры распределены по следующим группам в каталоге `Modules/`:

| Группа | Количество | Описание |
| --- | --- | --- |
| **OnlineRUS** | 21 | Российские бесплатные CDN: Collaps, Mirage, HDVB, Kinogo и другие |
| **OnlinePaid** | 9 | Платные источники с токенами: Rezka, Filmix, KinoPub, Alloha и другие |
| **OnlineAnime** | 12 | Аниме-платформы: AniLibria, Kodik, AnimeGo и другие |
| **OnlineENG** | 10 | Англоязычные источники для зарубежного контента |
| **OnlineUKR** | 8 | Украинские CDN для локального контента |
| **OnlineGEO** | 3 | Грузинские источники: Kinoflix, AsiaGe, Geosaitebi |
| **Adult** | 15 | Платформы 18+ для модуля SISI |

## Как настроить провайдера

Каждый провайдер настраивается в собственном разделе `init.conf`. Основные параметры:

| Параметр | Описание |
| --- | --- |
| `enable` | Включить или отключить провайдер |
| `host` | Базовый URL сервиса (если изменился домен) |
| `token` | API-ключ или токен доступа для платных источников |
| `priority` | Приоритет отображения в списке источников Lampa |

Пример конфигурации для платных провайдеров:

```json
{
  "Rezka": {
    "enable": true,
    "host": "https://rezka.ag",
    "priority": 1
  },
  "Filmix": {
    "enable": true,
    "host": "https://filmix.biz",
    "token": "ВАШ_ТОКЕН",
    "priority": 2
  },
  "KinoPub": {
    "enable": true,
    "token": "ВАШ_ТОКЕН"
  }
}
```

## Как отключить провайдера или группу

Существует два способа отключения:

1. **Отключить отдельного провайдера** — установите `"enable": false` в его секции `init.conf`.
2. **Отключить целую группу** — добавьте имя группы в `LoadModules` с исключающей маской или используйте `SkipModules` для конкретных модулей.

Пример отключения группы аниме через `LoadModules`:

```json
{
  "BaseModule": {
    "LoadModules": ["^(?!OnlineAnime).*"]
  }
}
```

Или добавьте конкретные модули в `SkipModules`:

```json
{
  "BaseModule": {
    "SkipModules": ["OnlineAnime"]
  }
}
```

<Note>
  Группа `OnlineRUS` включена по умолчанию и не требует дополнительной настройки. Платные провайдеры (`OnlinePaid`) нуждаются в токенах для полноценной работы.
</Note>

Lampac NextGen агрегирует аниме-контент из 12 источников и отдает его в приложение Lampa через плагин `/online.js`. Аниме-провайдеры объединены в группу `OnlineAnime` и загружаются вместе с VOD-ядром. Вы можете включать или отключать всю группу целиком, а также настраивать каждый провайдер отдельно.

## Список аниме-провайдеров

| Провайдер | Сервис | Примечания |
| --- | --- | --- |
| `AniLiberty` | AniLiberty | Русскоязычный аниме-сайт |
| `AniLibria` | AniLibria | Популярный русскоязычный дубляж |
| `AniMedia` | AniMedia | Аниме с русской озвучкой |
| `AnimeGo` | AnimeGo | Большая база аниме |
| `AnimeLib` | AnimeLib | Аниме-библиотека |
| `Animebesst` | AnimeBesst | Разнообразный аниме-контент |
| `Animevost` | Animevost | Аниме в озвучке AniVost |
| `Dreamerscast` | Dreamerscast | Аниме с русской озвучкой |
| `Kodik` | Kodik | Универсальный балансер: поддерживает и VOD, и аниме |
| `Mikai` | Mikai | Аниме-платформа |
| `MoonAnime` | MoonAnime | Аниме-источник |
| `AnimeON` | AnimeON | Аниме с мультиозвучкой |

<Note>
  `Kodik` — универсальный провайдер, который работает не только с аниме, но и с обычными фильмами и сериалами. Если вы используете Kodik для VOD, он автоматически покрывает и аниме-контент.
</Note>

## Включение и отключение аниме-группы

По умолчанию группа `OnlineAnime` загружается вместе с модулем Online. Чтобы полностью отключить все аниме-провайдеры, добавьте `OnlineAnime` в `SkipModules`:

```json
{
  "BaseModule": {
    "SkipModules": ["OnlineAnime"]
  }
}
```

Или используйте `LoadModules` для загрузки только нужных групп:

```json
{
  "BaseModule": {
    "LoadModules": ["OnlineRUS", "OnlinePaid", "OnlineAnime"]
  }
}
```

## Настройка отдельных провайдеров

Каждый аниме-провайдер настраивается в собственной секции `init.conf`. Пример для Kodik:

```json
{
  "Kodik": {
    "enable": true,
    "token": "ВАШ_ТОКЕН_KODIK",
    "priority": 1
  },
  "AniLibria": {
    "enable": true,
    "priority": 2
  },
  "AnimeGo": {
    "enable": true,
    "priority": 3
  }
}
```

| Параметр | Описание |
| --- | --- |
| `enable` | Включить или отключить провайдер |
| `token` | API-ключ (требуется для Kodik и некоторых других) |
| `priority` | Приоритет в списке источников Lampa (меньше = выше) |

## Особенности работы с аниме-провайдерами

- Большинство аниме-провайдеров не требуют токенов и работают сразу после включения.
- Для `Kodik` рекомендуется получить API-ключ для стабильной работы и доступа к полной библиотеке.
- Приоритеты помогают управлять порядком отображения источников в Lampa: провайдеры с меньшим значением `priority` показываются первыми.
- Если аниме не находится в одном источнике, Lampa автоматически перебирает остальные провайдеры из группы `OnlineAnime`.

Lampac NextGen поддерживает десятки VOD-провайдеров для просмотра фильмов и сериалов. Они разделены на три группы: российские бесплатные CDN, платные источники с API-токенами и грузинские сервисы. Каждый провайдер настраивается в собственной секции `init.conf`.

## Российские CDN (OnlineRUS)

| Провайдер | Примечания |
| --- | --- |
| `CDNvideohub` | Быстрый CDN с широкой библиотекой |
| `Collaps` | Поддерживает обычный и DASH-вариант |
| `FanCDN` | Специализированный CDN |
| `FlixCDN` | Фильмы и сериалы через CDN |
| `HDVB` | Популярный российский балансер |
| `Kinobase` | База фильмов с актуальными релизами |
| `Kinogo` | Один из старейших российских источников |
| `Kinotochka` | Разнообразный контент |
| `LeProduction` | Производственный контент |
| `Mirage` | Универсальный балансер с мультиозвучкой |
| `Phantom` | Новый источник с регулярными обновлениями |
| `PizdatoeHD` | HD-контент |
| `RutubeMovie` | Фильмы из экосистемы Rutube |
| `Spectre` | Актуальные релизы |
| `VeoVeo` | Работает через офлайн БД `data/veoveo.json` |
| `Vibix` | Разнообразная библиотека |
| `VideoDB` / `Videoseed` | Два связанных источника, маршруты `/lite/videodb` и `/lite/videoseed` |
| `VkMovie` | Контент из ВКонтакте |
| `Zetflix` / `ZetflixDB` | Два варианта одного сервиса |

<Note>
  Провайдер `VeoVeo` использует локальную офлайн-базу данных `data/veoveo.json`. Убедитесь, что этот файл присутствует в директории данных Lampac.
</Note>

## Платные источники (OnlinePaid)

| Провайдер | Примечания |
| --- | --- |
| `Alloha` | Платный балансер с широким выбором |
| `Filmix` | Основной вариант Filmix |
| `FilmixPartner` | Партнёрская версия Filmix |
| `FilmixTV` | ТВ-версия Filmix |
| `GetsTV` | Платный источник |
| `IptvOnline` | IPTV-ориентированный провайдер |
| `iRemux` | Remux-качество |
| `KinoPub` | Требует обязательный токен |
| `Rezka` | Популярный платный балансер |
| `RezkaPremium` | Премиум-версия Rezka |
| `SakhTV` | Региональный платный источник |
| `VoKino` | Платный VOD-сервис |

<Warning>
  `KinoPub` требует обязательный `token` в конфигурации. Без токена провайдер не будет работать. Получить токен можно в личном кабинете KinoPub.
</Warning>


## Как отключить VOD-провайдеров

Чтобы отключить конкретного провайдера, установите `"enable": false` в его секции. Чтобы отключить всю группу `OnlineRUS` или `OnlinePaid`, добавьте соответствующее имя в `SkipModules`:

```json
{
  "BaseModule": {
    "SkipModules": ["OnlinePaid"]
  }
}
```

Или используйте `LoadModules` для точного контроля загружаемых групп:

```json
{
  "BaseModule": {
    "LoadModules": ["OnlineRUS", "OnlineAnime"]
  }
}
```

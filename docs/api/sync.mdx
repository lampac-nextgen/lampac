| Модуль | Метод | Путь |
| --- | --- | --- |
| Sync | `GET` | `/sync.js`, `/invc-ws.js` |
| Sync | `GET`, `POST` | `/bookmark/list`, `/bookmark/set`, `/bookmark/add`, `/bookmark/remove` |
| Storage | `GET`, `POST` | `/storage/get`, `/storage/set`, `/storage/temp/{key}` |
| Storage | `GET` | `/backup.js` |
| TimeCode | `GET` | `/timecode.js`, `/timecode/all` |
| TimeCode | `POST` | `/timecode/add` |
| TimeCode | `GET` | `/timecode/dump`, `/timecode/changelog?since=&limit=` |
| TimeCode | `POST` | `/timecode/set` |

`/timecode/all` и `/timecode/add` сохраняют совместимость с веб-клиентом Lampa. Для нативных клиентов используйте `/timecode/dump` для первичной загрузки, затем `/timecode/changelog` для дельт. Параметр `limit` ограничен значением `20000`.

`POST /timecode/set` принимает одну запись, массив записей или объект `{ rows }`. Чтобы удалить запись, передайте её с `deleted: true`.

Starter-конфиг исключает Sync и TimeCode. См. [Sync](/modules/sync).

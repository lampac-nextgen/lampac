Вся настройка Lampac NextGen хранится в `init.conf` (JSON) или `init.yaml` (YAML) рядом с `Core.dll`. Watcher перечитывает поддерживаемые runtime-параметры без перезапуска. Изменения listener, состава модулей, manifest и startup services требуют рестарта. Резервные копии сохраняются в `database/backup/init/`, а отсутствующие значения дополняются из `base.conf`.

## Полный пример базовой конфигурации

Ниже приведён аннотированный пример `init.conf` с ключевыми параметрами, которые понадобятся при первой настройке сервера.

```jsonc
{
  // Режим низкой памяти: экономия ~140 МБ RSS
  "lowMemoryMode": true,

  // Сетевые настройки
  "listen": {
    "ip": "any",
    "port": 9118,
    "scheme": "http",
    "version": true,
    "ResponseCancelAfter": 15
  },

  // Управление модулями
  "BaseModule": {
    "SkipModules": ["Catalog", "DLNA", "JacRed", "Sync", "TimeCode", "TorrServer", "Tracks", "Transcoding", "WebLog"],
    "LoadModules": [".*"],
    "ValidateRequest": false,
    "BlockedBots": false
  },

  // Кеш: продление TTL при обращении
  "cache": {
    "extend": 180
  },

  // Playwright: автоматизация браузера
  "chromium": {
    "enable": true,
    "executablePath": "/usr/bin/chromium"
  },
  "firefox": {
    "enable": false,
    "count": 1
  },

  // Remote Client Hub: WebSocket-реле
  "rch": {
    "enable": false,
    "requiredConnected": 1
  },

  // Логирование в файл (logs/, ротация 14 дней)
  "serilog": false,

  // Управление памятью GC
  "GC": {
    "Concurrent": true,
    "ConserveMemory": 0,
    "HighMemoryPercent": 90,
    "RetainVM": false
  },

  // Шифрование потоков
  "kit": {
    "aesgcmkeyName": ""
  }
}
```

## Настройка сети (listen)

Раздел `listen` управляет сетевым слоем ASP.NET Core. Изменение IP, порта, Unix socket или TLS требует перезапуска процесса.

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `ip` | string | `"any"` | Интерфейс: `"any"` (все адреса), `"broadcast"` или конкретный IP вроде `"0.0.0.0"` / `"127.0.0.1"` |
| `port` | int | `9118` | TCP-порт сервера |
| `scheme` | string | не задан | Схема (`http` или `https`) в ссылках, которые Lampac вписывает в ответы. TLS не включает. Если не задан, берётся схема запроса. За HTTPS-proxy см. [reverse proxy](/deployment/reverse-proxy) |
| `version` | bool | `true` | Добавлять заголовок с версией сервера |
| `ResponseCancelAfter` | int | `10` | Таймаут ответа в секундах |

```json
{
  "listen": {
    "ip": "any",
    "port": 9118,
    "scheme": "http",
    "version": true,
    "ResponseCancelAfter": 10
  }
}
```

## Управление модулями (BaseModule)

`BaseModule` определяет, какие модули загружаются при старте сервера. Есть два механизма фильтрации:

- `SkipModules`: имена модулей, которые не загружаются даже если код присутствует в образе
- `LoadModules`: белый список по имени, группе (например, `OnlineUKR`) или регулярному выражению (например, `LME.*`)

```json
{
  "BaseModule": {
    "SkipModules": ["Catalog", "DLNA", "JacRed", "Sync", "TimeCode", "TorrServer", "Tracks", "Transcoding", "WebLog"],
    "LoadModules": [".*"],
    "ValidateRequest": false,
    "BlockedBots": false
  }
}
```

<Note>
  В `example.init.conf` в `SkipModules` указаны Catalog, DLNA, JacRed, Sync, TimeCode, TorrServer, Tracks, Transcoding и WebLog. `base.conf` дополнительно исключает CacheMedia, ForkPlayerXML, MsxNative, Potok, TelegramAuth и TelegramAuthBot. WAF и accsdb имеют `"enable": false`.
</Note>

## Кеш (cache)

Раздел `cache` управляет поведением файлового кеша. Параметр `extend` задаёт количество минут, на которое продлевается TTL записи при каждом обращении.

```json
{
  "cache": {
    "extend": 180
  }
}
```

## Playwright (chromium и firefox)

Playwright используется для автоматизации браузера при обходе JS-защит на стороне провайдеров. В Docker-образе зависимости уже включены. Для нативной установки потребуется дополнительная команда `playwright install chromium`.

```json
{
  "chromium": {
    "enable": false,
    "count": 1,
    "restart": 3600,
    "executablePath": "/usr/bin/chromium",
    "Args": ["--no-sandbox"]
  },
  "firefox": {
    "enable": false,
    "count": 1
  }
}
```

| Параметр | Описание |
| --- | --- |
| `enable` | Включить пул браузеров |
| `count` | Количество экземпляров в пуле |
| `restart` | Интервал полного перезапуска экземпляра, секунды |
| `executablePath` | Путь к бинарнику, если автоопределение не подошло |
| `Args` | Дополнительные флаги командной строки браузера |

## RCH (Remote Client Hub)

RCH — WebSocket-реле для клиентов, находящихся за NAT. Позволяет устройствам подключаться к серверу без проброса портов.

```json
{
  "rch": {
    "enable": false,
    "requiredConnected": 1
  }
}
```

Результаты принимаются через `POST /rch/result` и `/rch/gzresult`, состояние проверяется на `/rch/check/connected`. NativeWebSocket при `BaseModule.nws` доступен по `/nws`.

## Настройка провайдеров

Каждый провайдер контента настраивается в собственном разделе `init.conf`. Набор параметров зависит от конкретного источника.

```jsonc
{
  "Rezka": {
    "enable": true,
    "host": "https://rezka.ag",
    "priority": 1
  },
  "Filmix": {
    "enable": true,
    "host": "https://filmix.biz",
    "token": "TOKEN",
    "priority": 2
  },
  "KinoPub": {
    "enable": true,
    "token": "TOKEN"
  },
  "Kodik": {
    "enable": true,
    "token": "TOKEN"
  }
}
```

| Параметр | Описание |
| --- | --- |
| `enable` | Включить или выключить провайдер |
| `host` | URL хоста для провайдеров с настраиваемым зеркалом |
| `token` | API-токен или ключ партнёра |
| `priority` | Порядок в списке источников: меньше значение — выше в списке |

## Горячая перезагрузка без рестарта

<Note>
  Watcher проверяет конфигурацию примерно каждую секунду. Модульные настройки, которые подписаны на `EventListener.UpdateInitFile`, обновляются автоматически; startup-настройки требуют рестарта.
</Note>

## Минимальный example.init.conf

Ниже приведён точный `example.init.conf`, который поставляется с проектом. Это минимальная конфигурация для первого запуска.

```json
{
  "listen": { "version": true, "ip": "any", "port": 9118, "scheme": "http", "localhost": "127.0.0.1" },
  "BaseModule": { "SkipModules": ["Catalog","DLNA","JacRed","Sync","TimeCode","TorrServer","Tracks","Transcoding","WebLog"] },
  "chromium": { "enable": true, "executablePath": "/usr/bin/chromium" },
  "openstat": { "enable": true },
  "online": { "name": "Lampac NextGen", "spiderName": "Lampac NextGen", "version": true, "btn_priority_forced": true },
  "sisi": { "lgbt": false, "spider": false, "NextHUB": true, "history": { "enable": false } }
}
```

<Tip>
  Файл `config/base.conf` содержит дефолтные значения для всех параметров. Если параметр не указан в вашем `init.conf`, используется значение из `base.conf`. Это позволяет держать ваш конфиг минимальным и переопределять только то, что нужно.
</Tip>

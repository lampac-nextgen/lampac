Модуль **SISI** предоставляет контент 18+ для приложения Lampa через плагин `/sisi.js`. Ядро модуля включает SQLite-базу для истории просмотров и закладок, а также агрегирует 15 внешних платформ, каждая из которых реализована в отдельном проекте под `Modules/Adult/`. Маршруты платформ защищены лимитами WAF, а данные пользователя хранятся локально.

## Ключевые маршруты

| Маршрут | Назначение |
| --- | --- |
| `/sisi.js` | Основной плагин 18+ для Lampa 3.0 |
| `/sisi/js/{token}` | Плагин с авторизацией по токену |
| `/sisi/bookmark` | Управление закладками пользователя |
| `/sisi/history` | История просмотров |

## Конфигурация

Секция `sisi` в `init.conf` управляет поведением модуля и плагина.

```json
{
  "sisi": {
    "lgbt": false,
    "NextHUB": true,
    "history": { "enable": false }
  }
}
```

| Параметр | Назначение |
| --- | --- |
| `lgbt` | Включить LGBT-контент в плагине |
| `NextHUB` | Показывать ссылку на модуль NextHUB в интерфейсе |
| `history.enable` | Включить локальную историю просмотров в SQLite |

## NextHUB и SISI

**SISI** (ядро + `Modules/Adult/*`) — это нативные C#-источники с фиксированными маршрутами. **NextHUB** (`Modules/NextHUB`) — отдельный модуль для десятков сайтов на YAML с маршрутом `/nexthub`. Оба относятся к контенту 18+, но не дублируют друг друга. NextHUB описан в разделе [NextHUB](/modules/tg-notify), а в SISI он может быть доступен как дополнительная ссылка при включённом параметре `NextHUB`.

## Защита WAF

При инициализации модуля SISI автоматически добавляются лимиты WAF для путей платформ:

| Паттерн | Лимит |
| --- | --- |
| `/(sisi\|bgs\|chu\|runetki\|elo\|epr\|hqr\|phub\|ptx\|sbg\|tizam\|xmr\|xnx\|xds)` | 5 запросов в секунду |

<Note>
  Закладки и история просмотров хранятся в локальной SQLite-базе (`SisiContext`). При старте ядра SISI создаются каталоги `wwwroot/bookmarks/img` и `wwwroot/bookmarks/preview` для сохранения обложек закладок, если это включено в конфиге.
</Note>
